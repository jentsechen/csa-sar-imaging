\section{緒論與研究動機}

\subsection{背景}
合成孔徑雷達（SAR）原始資料透過下傳鏈路傳送至地面站，並在地面完成聚焦成像、影像強化與船舶偵測；偵測到的船舶目標可提供海事監控所需的位置與目標資訊。

\begin{figure}[htbp]
  \centering
  \includegraphics[width=0.6\textwidth]{../../group_meeting/figures/intro/ground_based_sar_ship_detection.png}
  \caption{地面式 SAR 船舶偵測處理流程示意圖。}
\end{figure}

本計畫的核心精神，是利用壓縮感測（Compressed Sensing, CS）理論：若待重建訊號具有稀疏性（sparsity），便可由遠少於 Nyquist 取樣定理所需的量測數，透過稀疏正則化準確重建 \cite{donoho_cs, candes_cs}：
\begin{equation}
  \hat{\mathbf{H}} = \arg\min_{\mathbf{H}}
    \underbrace{\frac{1}{2}\left\|\mathbf{Y} - \mathcal{A}(\mathbf{H})\right\|_F^2}_{\text{符合觀測到的回波}}
    + \lambda \underbrace{R(\mathbf{H})}_{\text{稀疏性限制}}
  \label{eq:cs-formulation}
\end{equation}
其中 $\mathbf{Y}$ 為原始回波、$\mathbf{H}$ 為待重建之場景反射率影像、$\mathcal{A}(\cdot)$ 為成像前向算子（見 4.2 節），$R(\mathbf{H})$ 為稀疏誘導正則項：理想上應為 $\ell_0$ 範數，但非凸且 NP-hard，故常以其凸鬆弛 $\ell_1$（或 $\ell_p$，$0<p<1$）取代。本報告以 $R(\mathbf{H})=\left\|\mathbf{H}\right\|_1$ 作為現階段示範（對應第 5.2 節之 soft-thresholding 解），並非最終選定，後續將視需要延伸至其他形式。

海面 SAR 場景恰好符合此稀疏性假設：海面雜訊背景均勻、反射率低，船舶則是少數強散射點，使場景反射率 $\mathbf{H}$ 本身即具稀疏結構。這也是本研究以「船舶偵測」作為評估任務的原因：偵測表現的提升與否，可直接反映稀疏正則化（式 \eqref{eq:cs-formulation}）強化 SAR 影像的實際效益。

\subsection{問題與動機}
本研究欲解決以下問題：
\begin{itemize}
  \item 地面式處理：原始資料量大、下傳頻寬有限，導致目標資訊延遲。
  \item 星載（onboard）處理：僅需下傳偵測到的目標資訊而非完整原始資料，可降低下傳鏈路頻寬需求，並縮短從下傳到地端處理完成的延遲，但受限於運算能力、記憶體與功耗。
  \item Speckle noise 干擾：SAR 屬同調成像系統，影像中不可避免存在乘性 speckle noise；雜訊亮點可能被誤判為船舶（false positive），也可能掩蓋真實的弱散射目標（false negative），須加以抑制才能確保偵測結果可信。
\end{itemize}
上述問題中，星載運算資源有限與 speckle noise 抑制看似為兩個獨立需求，但壓縮感測可一併回應：真實場景反射率本身是稀疏的（見 1.1 節），而 speckle noise 是疊加在每個像素上的乘性擾動，會使原本接近零的背景像素被抬高、變得雜訊化；式 \eqref{eq:cs-formulation} 之稀疏正則化利用場景稀疏的先驗，將振幅低（多為雜訊擾動的背景）的像素壓制為零，同時保留振幅本來就高的目標像素，因此能以同一套輕量化框架兼顧抑制 speckle noise 與低運算量兩項需求。

\subsection{研究目標}
本計畫原訂之研究範疇涵蓋 speckle 統計建模與噪聲注入模擬、以壓縮感測為基礎的即時 SAR 成像、去斑（despeckle）方法比較、以及以 YOLO 為基礎之船舶偵測評估等階段。本節之研究目標即回應 1.2 節所列之三項痛點：

\begin{itemize}
  \item 即時性之必要性：船舶偵測若僅能於地面事後處理完成，則難以支援即時海事監控需求；成像方法須兼顧運算效率，使其可行於星載平台之算力與功耗限制下，方能達成低延遲之目標資訊回傳。
  \item 為何引入壓縮感測：如 1.1、1.2 節所述，星載平台受限於運算資源，須採用輕量化的成像方法；而壓縮感測之稀疏正則化機制，在以遠少於 Nyquist 取樣所需的量測數重建場景的同時，天然具備抑制 speckle noise 的能力。因此壓縮感測可同時回應「低運算量」與「speckle noise 抑制」兩項需求，是本計畫選擇以其為核心方法的原因。
  \item 如何處理 speckle noise：規劃先以統計方式建模 SAR 影像中 speckle noise 的分布與 number of looks 等參數，並將其注入模擬回波中，以在具真實統計特性的資料上，比較稀疏正則化與傳統去斑方法之效果。
\end{itemize}

\section{文獻探討}

\subsection{壓縮感測於 SAR 影像重建之應用}
稀疏正則化已廣泛用於 SAR 影像重建，但訴求多為提升重建影像品質，而非下游應用任務：
\begin{itemize}
  \item Bi \textit{et al.} \cite{sparse_sar_imaging}：$\ell_1$ 正則化＋soft-thresholding，訴求降低運算複雜度以利即時成像（本報告 5.2 節即參考此法）。
  \item Zhang \textit{et al.} \cite{zhang_reweighted}：multi-segment-reweighted 正則化，訴求改善 $\ell_1$ 造成的振幅失真。
  \item Liu \textit{et al.} \cite{liu_compound_reg}：$\ell_{1/2}$＋TV 複合正則化，訴求處理低過採樣資料並保留空間結構。
\end{itemize}
三者皆以影像品質指標評估，未涉及下游偵測任務。

\subsection{SAR 船舶偵測之既有研究}
近期研究多將 speckle noise 抑制放在偵測網路的特徵層級，而非影像域：
\begin{itemize}
  \item SARES-DEIM \cite{sares_deim}：DETR + Mixture-of-Experts，特徵層級抑制 speckle noise，於 HRSID 上 mAP@0.5:0.95 由 YOLOv11 之 67.7\% 提升至 76.4\%。
  \item CVMT \cite{cvmt}：雙分支複數值 Transformer，以 Super Feature Learning 於特徵層級抑制雜訊，於 OpenSARShip / FAIR-CSAR 達 SOTA。
\end{itemize}
兩者皆以已成像影像為輸入、採大型 Transformer 架構，訓練與推論成本高。

\subsection{本研究之定位與差異性}
本研究將稀疏正則化直接嵌入「回波 $\to$ 成像 $\to$ 稀疏精修」流程，並以船舶偵測表現（Precision/Recall/mAP@0.5）評估其效益——相較 2.1 節僅評估影像品質，本研究更貼近實際應用；相較 2.2 節之 Transformer 架構，本研究改用計算量低廉、具封閉解的 $\ell_1$ soft-thresholding（見 5.2 節）搭配輕量化 YOLO，較適合星載平台之算力限制。

可能缺點：目前僅用影像域 $\ell_1$ 正則化，尚未與特徵層級抑制或傳統去斑濾波器比較，其在近岸雜訊、小型目標上的效果仍待驗證（見 1.3 節未完成工作項目）。

\section{SAR 回波與成像模型}

\subsection{點散射體回波模型：幾何關係}
\label{subsec:point-scatterer}
輸入 SAR 影像中每個像素的 range location（行）、azimuth location（列）與 intensity（強度值），分別轉換為對應散射體的 range、Doppler（即下述之距離偏移 $d_k$、方位時間偏移 $\Delta\eta_k$）與 magnitude（散射係數 $A_k$，見下節訊號合成）。成像於斜距（slant range）方向進行，像素對應的距離偏移即為散射體 $k$ 之斜距偏移 $d_k$。

目標位置決定了隨慢時間 $\eta_m$ 變化的斜距 $R_k(\eta_m)$：
\begin{equation}
  R_k(\eta_m) = \sqrt{R_{0,k}^2 + (\eta_m + \Delta\eta_k)^2 V_r^2}
\end{equation}
其中 $R_{0,k} = R_0 + d_k$：
\begin{itemize}
  \item $R_0$：場景中心的斜距
  \item $d_k$：散射體 $k$ 相對場景中心之斜距方向距離偏移
  \item $\eta_m = m\Delta\eta$：慢時間
  \item $\Delta\eta_k$：散射體 $k$ 相對場景中心的方位時間偏移
\end{itemize}

\begin{figure}[htbp]
  \centering
  \includegraphics[width=0.55\textwidth]{../../group_meeting/figures/point_scatterer/point_target_geometry.png}
  \caption{點散射體回波模型幾何關係示意圖。}
\end{figure}

\subsection{訊號合成}
延遲與相位皆為幾何相依：
\begin{equation}
  \tau_k(\eta_m) = \frac{2R_k(\eta_m)}{c}, \qquad
  \phi_k(\eta_m) = -4\pi \frac{R_k(\eta_m)}{\lambda}
\end{equation}
回波訊號矩陣 $\mathbf{S} = [s_{m,n}]_{M\times N}$ 由下式合成：
\begin{equation}
  s_{m,n} = \sum_k A_k\,\mathrm{rect}\!\left(\frac{\tau_n - \tau_k(\eta_m)}{T_r}\right)
    \cdot e^{j\pi K_r\left(\tau_n - \tau_k(\eta_m)\right)^2}
    \cdot e^{j\phi_k(\eta_m)}
\end{equation}
其中：
\begin{itemize}
  \item $\eta_m = m\Delta\eta$：慢時間；$\tau_n = n\Delta\tau$：快時間
  \item $A_k$：散射體 $k$ 的散射係數
  \item $K_r = B_r / T_r$：chirp 調頻率；$B_r$：chirp 頻寬（Hz）；$T_r$：脈衝時寬（秒）
\end{itemize}

  \includegraphics[width=\textwidth]{../../group_meeting/figures/pipeline/csa_flow.png}
  \caption{CSA 七步驟處理流程}
  \label{fig:csa-flow}
\end{figure}
其中 Chirp Scaling 步驟（演算法命名之由來）以下式相位相乘，修正隨距離變化之徙動量：
\begin{equation}
  \exp\left\{j\pi K_m\left[\frac{D(f_{\eta_{\mathrm{ref}}})}{D(f_\eta)}-1\right]\left(\tau - \frac{2R_{\mathrm{ref}}}{cD(f_\eta)}\right)^2\right\}, \qquad
  D(f_\eta) = \sqrt{1-\frac{c^2f_\eta^2}{4V_r^2f_0^2}}
\end{equation}
$D(f_\eta)$ 為徙動參數、$K_m$ 為修正後之距離調頻率、$R_{\mathrm{ref}}$ 為參考距離。此相位相乘使不同距離目標之徙動量趨於一致，後續距離壓縮即可對全場景套用同一匹配濾波器，避免內插運算。

參考距離 $R_{\mathrm{ref}}$ 設為模擬場景正中央對應的斜距，與第 \ref{subsec:point-scatterer} 節之場景中心斜距 $R_0$ 為同一值（幅寬 swath width、幅長 swath length 之定義見第 \ref{subsec:sim-setup} 節）；場景中其餘散射體之距離、方位偏移 $d_k$、$\Delta\eta_k$（第 \ref{subsec:point-scatterer} 節）皆相對此中心點定義。

\subsection{One-Step 稀疏影像精修}
在影像域施加稀疏正則化 \cite{sparse_sar_imaging}：
\begin{equation}
  \hat{\mathbf{H}} = \arg\min_{\mathbf{H}}
    \underbrace{\frac{1}{2}\left\|\mathbf{H}-\mathbf{H}_{\mathrm{CSA}}\right\|_F^2}_{\text{保留 CSA 影像資訊}}
    + \lambda \underbrace{\left\|\mathbf{H}\right\|_1}_{\text{提升稀疏性}}
\end{equation}
此問題可逐元素求得閉式解（soft-thresholding）：
\begin{equation}
  \hat{\mathbf{H}} = \mathcal{S}_\lambda(\mathbf{H}_{\mathrm{CSA}}), \qquad
  \mathcal{S}_\lambda(x) = \frac{x}{|x|}\max(|x|-\lambda, 0),\ x \neq 0
\end{equation}
強散射體被保留，弱散射成分（如背景雜訊）則被抑制，整體處理流程為單一步驟：
\[
  \mathbf{Y} \xrightarrow{\text{CSA}} \mathbf{H}_{\mathrm{CSA}} \xrightarrow{\mathcal{S}_\lambda(\cdot)} \hat{\mathbf{H}}
\]

\subsection{模擬設定}

表 \ref{tab:sim-params} 中的最近斜距即第 \ref{subsec:conventional-sar} 節之參考距離 $R_{\mathrm{ref}}$（$=R_0$），設為模擬場景正中央對應的斜距。模擬影像尺寸為 $800\times800$ 像素：距離向幅寬（swath width）為影像距離向像素數乘上距離向像素間距，即 $800 \times c/(2f_s) \approx 1875$ m；方位向幅長（swath length）為影像方位向像素數乘上方位向像素間距，即 $800 \times V_r/\mathrm{PRF} = 96$ m；其中取樣頻率 $f_s$ 與平台速度 $V_r$ 之數值代入表 \ref{tab:sim-params}。$R_{\mathrm{ref}}$ 對應距離向幅寬正中央的斜距，方位時間零點（$\eta_m=0$）則對應方位向幅長的正中央。

目前參數設定採用機載（airborne）平台（如平台速度 120 m/s、最近斜距 4000 m），後續將調整為星載（spaceborne）SAR 系統的典型參數。

\subsection{船舶偵測表現}
精修門檻值設為 120（強度範圍 0–255）。門檻化能抑制 CSA 造成的背景假影，並提升船舶偵測表現，如表 \ref{tab:ship-perf}。
由於本實驗僅自離岸影像中取樣 100 張進行模擬，表 \ref{tab:ship-perf} 中「原始 SAR 影像」的偵測表現與表 \ref{tab:yolo-results}並不完全相同；但由於原始 SAR 影像、CSA、CSA + 稀疏精修三者皆在同一組 100 張影像上評估，彼此之間的比較仍然公平。

\section{結論}

\subsection{本階段已完成的工作}
\begin{itemize}
  \item 建立了以船舶偵測評估 SAR 影像強化效果的端對端框架。
  \item One-step 稀疏精修能在保留主要船舶響應的同時抑制背景假影。
  \item CSA + 稀疏精修將偵測表現由 mAP@0.5 = 0.954 提升至 0.985。
\end{itemize}

\subsection{後續工作}
\begin{itemize}
  \item 嘗試不同的影像域正則化方法。
  \item 將 speckle noise 納入模擬情境中一併評估。
  \item 將模擬參數由機載（airborne）調整為星載（spaceborne）SAR 系統的典型參數。
  \item 提升成像解析度（如提高頻寬以改善距離向解析度），並探討解析度對船舶偵測辨識率的影響。
\end{itemize}
